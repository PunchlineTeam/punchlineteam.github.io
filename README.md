# punchlineteam.github.io

Redirects the organization's root Pages address to the studio site at
[punchlineteam.com](https://punchlineteam.com/), which is built from
[PunchlineTeam/Portfolio](https://github.com/PunchlineTeam/Portfolio).
`404.html` sends any other path there too. (`/Portfolio/` itself is redirected
by GitHub, since that repository has the custom domain.)
